## 关于「爱发电认证网站」

需要澄清一个常见误解：**爱发电的「认证」不是域名所有权验证**，不需要 DNS TXT 记录、meta 验证码或上传验证文件。它是平台工作人员**人工确认「这个主页确实是创作者本人」**的审核。

爱发电官方创作者 FAQ 给出的三条通过标准：

1. 正确填写**完整、有效**的主页网址链接（不是 ID、昵称、网站名字）
2. 主页网址中**公开宣传了爱发电**，或在签名、公告等处标注
3. 主页网址中**有创作内容**，不要拿空白账号认证

本仓库对应的落实方式：

- 官网首屏顶部公告条、Hero 按钮、赞助区、页脚均**公开标注**爱发电，并以纯文本写出完整地址 `https://afdian.com/a/CCief`，链接使用真实 `<a href>` 且带 `rel="me"` 身份归属标记
- `support.html` 专门声明本人身份、本站网址与官方爱发电主页地址的对应关系，并逐条列出上述审核标准
- 首页与 `CHANGELOG.md` 提供真实的项目介绍与更新日志，不是空白站点

申请入口：<https://afdian.com/apply/certify>（需先成为创作者；审核一般由工作人员在 2 个工作日内处理，并通过私信通知）。提交时建议填写官网首页，或专门的 `https://ccief.github.io/DigForWealth/support.html`。

## 维护更新日志

1. 编辑根目录 [`CHANGELOG.md`](CHANGELOG.md)，按日期倒序新增条目
2. 同步更新 `index.html` 中 `<!-- CHANGELOG:START -->` 与 `<!-- CHANGELOG:END -->` 之间的静态日志区

日志区刻意写成**静态 HTML**而非 JS 动态渲染，是为了让审核人员与爬虫在不执行脚本的情况下也能读到创作内容。新增条目时请一并保留「注：内容由AI辅助生成」声明。
